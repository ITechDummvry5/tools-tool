# NameTag Studio

A simple browser-based name tag generator for creating customizable and printable name tags.

## Features

- Create name tags
- Add names and additional information
- Customize the name tag
- Preview the design
- Print generated name tags
- Browser-based and lightweight

## Tech Stack

- HTML
- CSS
- JavaScript
