# Usage

## 1. Enter Information

Enter the name you want to display on the name tag.

Add additional information if available, such as:

- Position
- Role
- Organization
- Department

## 2. Customize

Adjust the available name tag options to create the desired design.

## 3. Preview

Review the generated name tag before printing.

## 4. Print

Use the print option to print the generated name tag.

## Tips

- Check spelling before printing.
- Use clear and readable names.
- Preview the design before printing multiple copies.
