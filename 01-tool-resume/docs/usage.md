# Usage

## 1. Enter Name

Enter the person's name in the name field.

## 2. Add Details

Optionally enter information such as:

- Position
- Organization
- Department

## 3. Customize

Adjust the available name tag options.

## 4. Preview

Check the generated name tag before printing.

## 5. Print or Download

Use the available action to print or save the generated name tag.
