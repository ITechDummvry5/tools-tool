# Project Overview

## Introduction

The Text to Voice Converter is a web application that allows users to enter text and listen to it using a voice available on their device.

The application provides a simple interface with a text input area, voice selection dropdown, and Listen button.

## Purpose

The purpose of this project is to demonstrate how HTML, CSS, and JavaScript can be used with the browser's Web Speech API to create a text-to-speech application.

## Main Components

### HTML

The HTML file provides the structure of the application, including:

- Page heading
- Description
- Text area
- Voice selection dropdown
- Listen button

### CSS

The CSS file controls the visual appearance of the application, including:

- Layout
- Colors
- Typography
- Buttons
- Form controls
- Responsive design

### JavaScript

The JavaScript file provides the functionality of the application.

It can:

1. Read the text entered by the user.
2. Retrieve available voices.
3. Allow the user to select a voice.
4. Convert the text into speech.
5. Play the generated speech.

## Web Speech API

The application uses the browser's built-in Speech Synthesis API.

Available voices may vary depending on the browser, operating system, and installed speech services.
