# Text to Voice Converter

A simple web-based Text to Voice Converter that converts written text into spoken audio using the browser's Web Speech API.

## Features

- Enter text into a text area.
- Select a voice.
- Convert text to speech.
- Listen to the generated speech.
- Simple and responsive interface.
