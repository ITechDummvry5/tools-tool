# Project Overview

## What is Product Customizer?

Product Customizer is the VYRE Gear Customizer interface. It provides a live hero preview where a model image can be customized using colors, intensity, blend modes, application targets, and solid or gradient effects. The supplied file defines the VYRE Gear Customizer title and interface. fileciteturn2file0L1-L8

## Main Areas

The interface is divided into:

1. Topbar
2. Left customization panel
3. Center live hero preview
4. Right information panel

## Topbar

The topbar contains VYRE branding, the Gear Customizer title, Reset, and Export CSS controls. fileciteturn2file0L293-L304

## Left Panel

The left panel contains controls for:

- Model Image
- Gear Color
- Blend Mode
- Apply To
- Effect Type

The image uploader accepts PNG, JPG, and WEBP according to the interface text. fileciteturn2file0L309-L325
