# Product Customizer

Product Customizer is a browser-based VYRE Gear Customizer for uploading a model image and applying live color, blend, intensity, target, and effect customizations.

## Features

- Upload PNG, JPG, or WEBP images.
- Drag and drop images.
- Live hero preview.
- Predefined gear color palette.
- Custom color picker.
- Intensity control from 0% to 80%.
- Blend modes: Color, Multiply, Screen, Overlay, Hue, Luminosity.
- Apply effects to Image, Container, or Section.
- Solid and Gradient effect types.
- Second color picker for gradients.
- Reset customization.
- Copy generated CSS to the clipboard.
