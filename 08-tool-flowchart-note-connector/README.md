# FlowNotes

FlowNotes is a browser-based flowchart and note-board tool for visually organizing pages, actions, forms, links, media, data, and payment-related steps.

## Features

- Add cards using multiple visual layouts.
- Drag cards around the canvas.
- Pan the canvas by dragging the background.
- Zoom in and out and reset the view.
- Create connections between cards.
- Add labels and colors to connections.
- Edit supported card text directly on the canvas.
- Delete individual cards or clear the canvas.
- Use a dark, compact interface designed for flowchart-style work.

## Card Types

FlowNotes currently supports:

1. Hero Banner
2. Section Label
3. Page Card
4. Action Card
5. External Link
6. Media / Gallery
7. Form Card
8. Data Card
9. Payment Card
