# Usage

## 1. Open Weather App

Launch `weather.html` in a modern web browser.

## 2. Search for a City

Use the search field with the placeholder:

```text
Search city...
```

Then use the adjacent search button. fileciteturn4file0L25-L29

## 3. View Weather Information

The main weather card provides areas for:

```text
Location
Date
Temperature
Temperature
Condition
Humidity
Wind
Precip.
```

## 4. View Weather Icon

The weather card displays a weather image using:

```text
images/sunny.png
```

The image is identified as the weather icon. fileciteturn4file0L41-L43

## 5. View Extra Information

The page provides three additional cards:

```text
Current Weather
Percentages
Threats
```

```text
Open Weather App

Search City

```

## Important Note

The supplied HTML defines the interface but does not provide the implementation of `weather.js`. Therefore, the exact search process, weather-data source, API behavior, and how the displayed values are populated cannot be determined from this HTML alone.
