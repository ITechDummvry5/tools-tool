# Project Overview

## What is Weather App?

Weather App is a weather interface with a search area and a weather information card. The supplied HTML identifies the page title as **Weather App** and references external CSS and JavaScript files. fileciteturn4file0L3-L8

## Main Areas

The interface contains:

1. Decorative sun and moon shapes
2. Weather App header
3. City search
4. Weather card
5. Weather details
6. Three extra cards
7. Footer
