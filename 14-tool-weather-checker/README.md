# Weather App

Weather App is a browser-based weather interface with a city search field, weather card, temperature display, weather details, extra information cards, and decorative weather elements.

## Features

- Weather App header and logo.
- City search input.
- Search button.
- Weather card.
- Location and date display areas.
- Weather icon.
- Temperature display.
- Weather condition text.
- Humidity information.
- Wind information.
- Precipitation/pressure information.
- Three additional weather cards.
- Decorative sun and moon shapes.
- External CSS and JavaScript files.
