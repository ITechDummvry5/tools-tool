# Calculator App

Calculator App is a browser-based calculator interface with a themed layout, decorative background shapes, a calculator display, numeric/operator keypad, and a three-position theme switch.

## Features

- Calculator display initialized to `0`
- Numeric buttons from `0` to `9`
- Decimal point button
- Addition, subtraction, division, and multiplication controls
- `DEL` button
- `RESET` button
- `=` button
- Three-position theme selector labeled `1`, `2`, and `3`
- Decorative background shapes
- Responsive viewport configuration
- Separate CSS and JavaScript files
- Favicon support
