# Project Overview

## What is Password Feed?

Password Feed is an HTML interface titled **Password Strength Feed**, with the visible application heading **Password Feed**. The page is structured around a password input and strength feedback area.

## Main Areas

The interface contains:

1. Decorative shapes
2. Main container
3. Header
4. Password input
5. Check button
6. Strength bar
7. Strength text
8. Suggestion area
9. Footer

## Header

The header displays the application logo using `favicon.ico` and the title **Password Feed**.
