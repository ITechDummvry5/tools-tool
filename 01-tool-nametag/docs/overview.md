# Overview

The Name Tag Generator is a browser-based tool for quickly creating name tags.

## Purpose

The tool is designed to simplify the creation of name tags for:

- Events
- Conferences
- Meetings
- Seminars
- Workshops
- Organizations
- School activities

## Main Workflow

```text
Enter Information
       ↓
Customize Name Tag
       ↓
Preview
       ↓
Generate
       ↓
Print / Download
