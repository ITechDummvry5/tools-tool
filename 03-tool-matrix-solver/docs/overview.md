# Project Overview

## Matrix Calculator

Matrix Calculator is a client-side web application for performing common matrix calculations through an interactive cell-based interface.

The application allows users to create two matrices, Matrix A and Matrix B, by specifying their dimensions and entering values into dynamically generated cells.

## Purpose

The project is designed to provide a simple interface for learning and performing matrix operations without requiring a backend server.

It can be used for:

- Mathematics practice
- Matrix operation demonstrations
- Programming practice
- JavaScript DOM manipulation
- Educational projects

## Matrix Input

The application provides two independent matrices:

### Matrix A

Matrix A has configurable:

- Number of rows
- Number of columns
- Cell values

### Matrix B

Matrix B has configurable:

- Number of rows
- Number of columns
- Cell values

The matrix cells are generated based on the selected dimensions.

## Supported Operations

### Swap

Swaps the values and dimensions of Matrix A and Matrix B.

A ↔ B
