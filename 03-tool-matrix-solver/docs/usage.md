# Usage Guide

## 1. Open the Calculator

Open `index.html` in a modern web browser.

The Matrix Calculator interface will display Matrix A, Matrix B, operation controls, and the result areas.

## 2. Configure Matrix A

Use the `Rows` and `Cols` inputs under Matrix A.

For example:

```text
Rows: 2
Cols: 2
